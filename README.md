## Project 02 — Responsive Web Layout

### Description

A modern mobile-first portfolio website built to demonstrate responsive web design principles across mobile, tablet, and desktop devices.

This project focuses on creating flexible layouts using CSS Grid and Flexbox while maintaining accessibility, clean structure, and professional UI design. The website includes a responsive navigation system, hero section, about section, skills showcase, project cards, contact form with validation, and footer.

### Technologies

* HTML5
* CSS3
* Vanilla JavaScript
* CSS Grid
* Flexbox
* HTML Popover API
* Google Fonts (Inter)

### Key Concepts Demonstrated

* Mobile-First Development
* Responsive Design
* CSS Media Queries
* CSS Grid Layouts
* Flexbox Components
* Fluid Typography using `clamp()`
* CSS Variables (`:root`)
* Accessible Touch Targets
* Semantic HTML5
* Form Validation
* Smooth Scrolling Navigation
